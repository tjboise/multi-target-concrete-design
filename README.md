# FLAME: Front-guided LLM-Augmented Multi-objective Evolution

**FLAME** couples NSGA-II with a large language model (Gemini 2.5 Flash-Lite) for multi-objective concrete mix design. It simultaneously minimizes GWP (kg CO₂/m³) and maximizes 28-day compressive strength (MPa). At each generation, the LLM receives the current Pareto-elite solutions as few-shot examples and a structured knowledge table, and generates N = 15 candidate mixes that are appended to the NSGA-II offspring pool before environmental selection.

---

## Setup

```bash
pip install pymoo catboost joblib google-genai python-dotenv pandas numpy scipy matplotlib
```

Create a `.env` file in the project root:
```
GEMINI_API_KEY=your_key_here
```

**Dataset:** `Concrete_Data_SI_clean.csv` (667 records, kg/m³)  
**Surrogate model:** `../low_carbon_concrete/concrete_catboost_optimized_clean.pkl` (CatBoost-Chain, chained R² = 0.854)

## Reproducing Paper Figures

All figures are saved to `results/figures/`. Run scripts from the project root.

### Figure 1 — Pareto Front and HV Convergence (FLAME vs NSGA-II)

**Data required:** `results/nsweep_n15/rep{01-30}/` and `results/grid_everyg_base/rep{01-30}/`

**Run experiments (if not already done):**
```bash
# NSGA-II baseline (30 reps)
python run_experiment_mt.py --mode base --prefix grid_everyg_base --repeat 30

# FLAME N=15 (30 reps)
python run_nsweep.py --n 15 --prefix nsweep_n15 --repeat 30
```

**Generate figures:**
```bash
python regen_figures_n15.py
```

Outputs: `pareto_front_everyg.png`, `convergence_everyg.png`, `step2_area.png`, `step3_paired.png`
